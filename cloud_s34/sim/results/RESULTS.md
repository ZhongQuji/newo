## E1 只看结局：相图 (π × c)，a = 0.9

- **GRPO（除以组内 std）**：解析边界 c* = a − π 与模拟终态（P(C) > 0.5 判「查证」）符合率：全部 600 格 91.8%；去掉 |c − c*| ≤ 0.03 的边界格后 95.3%。经验 50% 等高线相对解析线的平均偏移 **Δc = -0.040**（负 = 边界向下移、查证的地盘变小）。

- **新发现（可写进论文）**：GRPO 的 std 归一化对「有成本的查证」有系统性偏置——当组内样本全部答对时（高 π、高 a 下很常见），组内方差极小，查证成本 c 这个微小差额被归一化放大成满幅负优势；而查证靠准确率赢的那些组方差大、优势被稀释。结果是 GRPO 的有效 c* 低于 a − π，即 **GRPO 比理论上的策略梯度更偏向盖章**。Dr. GRPO 去掉 std 后边界回到解析线。这是 Dr. GRPO 论文指出的「难度偏置」在本问题上的具体后果，也意味着 S31 用解析式 c*(π) 预测的「查证值得」区域对 GRPO 训练是偏乐观的。

## E4 自适应审计（「无为而治」控制器）：q 跟着观测到的审计失败率走，低了就松、高了就紧

控制律 q_{t+1} = clip(q_t + η·(观测失败率_t − τ), q_min, 1)，η = 0.1。观测失败率 = 被审账本里错误的比例（训练者看得到）。诚实查证也有 1 − a = 0.10 的失败率，所以 τ 必须 > 0.10（这里 0.15）；τ = 0.05 的「零容忍」会把 q 推到 1 并永远不松。

## E5 数据配比当奖励整形（大道至简：不加审计、不配孪生，只改数据配比）

- 期望奖励分析给出的临界配比 f* = (π_hi − (a − c))/(π_hi − π_lo) = **0.22**：完全共享策略下混入 ≥ 22% 的低基率提示，整体就该转向查证。
- **GRPO 实测（s = 1）**：f = 0.5 时高基率层 P(C) = 0.01、低基率层 0.01；f = 0.6 时 0.01 / 0.01；f = 0.7 时 0.79 / 0.79；f = 0.8 时 0.93 / 0.93。翻转点在 f ≈ 0.65，是期望奖励分析（0.22）的三倍；低于它时**两层一起**锁死为盖章（P9 的负迁移，强版本）。原因同 E1/E9：高 π 层的全对混合组给查证 −√7 的成本盲惩罚，低 π 层靠准确率赢的组归一化后只有 ≈ +0.8，一个抵三个。
- **Dr. GRPO 实测（s = 1）**：f = 0.25 时 0.69 / 0.69，f = 0.5 时 0.96 / 0.96——边界接近期望奖励分析的 f*。所以「只改数据配比」这条省 token 的路，在 GRPO 下不通、在 Dr. GRPO 下通。
- 共享度降低（s = 0.8 / 0.5）时两层各走各的：高基率层仍锁死、低基率层自救；配比的作用随共享度减弱。真实 LM 的共享度未知——P9 的实验正好可以标定它。

## E7 弃权陷阱：TAPO-RA 的「诚实弃权不审」什么时候会训出一个只会说「无法核验」的模型

- 弃权压过查证的解析条件：r_a > a − c − qκ(1 − a) ≈ 0.85 − 0.10·q。r_a = 0 时永远安全；若把弃权当「诚实」给正奖励（r_a ≥ 0.5），在 q 大时先吃掉盖章、再吃掉查证。
- 建议：论文里把 r_a 固定为 0 并说明理由，或报告这张相图作为 TAPO-RA 的安全边界。

- 「同组同动作 → 梯度恰为 0」对 GRPO 和 Dr. GRPO 都成立（组内优势之和为 0），REINFORCE+EMA 基线没有这个精确零点。但**决定锁死速度的不是零点，而是 std 归一化**：在全对的混合组里，GRPO 给带成本动作的归一化优势是 −√((G−k)/k)（k = 组内查证样本数），**与成本 c 的大小无关**——c = 0.001 和 c = 0.1 得到同样的 O(1) 惩罚。Dr. GRPO / REINFORCE 的优势正比于真实差额 0.05，漂移慢一个量级。
- 论文里的「零方差吸收态」应改写成两层：(i) group-relative 基线族（GRPO / RLOO / DAPO）有精确吸收态；(ii) GRPO 的 std 归一化把任意小的查证成本放大成满幅惩罚，是锁死快的直接原因。可检验预测：把 look_rl.py 的优势归一化换成只减均值（Dr. GRPO 一行改动），1.7B 的锁死步数应显著变长。
- G 越小、每步组数越多，锁死越快（逃逸概率 1 − (1 − p)^{G·n}）；这给「用更大的 G 延缓锁死」一个可检验的预测。

| drgrpo | 0.02 | 472 | 100% | 0.010 |
| drgrpo | 0.05 | 336 | 100% | 0.007 |
| drgrpo | 0.1 | 225 | 100% | 0.004 |
| drgrpo | 0.2 | 133 | 100% | 0.003 |

- 解析推导：组内 k 个查证、G−k 个盖章、全部答对时，GRPO 对查证样本的归一化优势 = (−c(G−k)/G) / (c√(k(G−k))/G) = −√((G−k)/k)，c 约掉。所以只要 c > 0，GRPO 就以同样的力度把查证推下去；Dr. GRPO 的推力正比于 c。
- 对论文的意义：「验证悖论」在 GRPO 下不是「成本太高才不查」，而是「只要查证多花一个 token，GRPO 就当成大事」。这把问题从数据分布（π）扩展到优化器（归一化），也给出了最便宜的缓解手段之一：去掉 std 归一化。
