# 《大越史記全書》接入说明（给有本机权限的会话写 `build_sky_vn.py` 用）

生成：2026-10-25（UTC+8）云端会话 S34。文本见同目录 `text/*.txt`（每卷一文件）与 `dvsktt_all.txt`；来源、修订号、sha256 见 `MANIFEST.json`；词频与样例见 `probe.md`。

## 1. 为什么值得接
- 这是 S33 六个全球来源里唯一没拿到的（当时试的越南站点是动态加载）。维基文库版是 30 卷全本（外紀 5 + 本紀 19 + 續編 5 + 卷首），55 万字，漢文。
- 可定到日的天象记录：**干支+朔+日食 27 条**（最硬，干支日是绝对的 60 日周期、不依赖越南历表）、月+朔+日食 33 条（朔日由历表定）、望/十五十六日月食 37 条（部分带时辰：戌時、卯時、五更初刻）、太白晝見/經天 13 条、月犯 8、行星犯 17。预计可进任务池的真实事件 60–90 条（与日本六国史 159、拉丁 46 同量级），负/正孪生按冻结规则生成。
- **第七种历法/政权**：王朝年号纪年（越南自定年号）+ 中国式干支 + 自铸历（陳朝以后有自己的历官，朔日和闰月可能与中原历差一天/一月，正如日本层遇到的情况），观测地升龙（河内）。跨政权命题（「盖章不是记忆」）又多一个独立点。
- 史料自带「核验者」：黎朝太史令裴時亨四条（`probe.md` 末节）——「妄奏是月十六日卯時月食，詔百官詣承天門救月，不見食」、「乙巳，月有食。太史裴時亨密奏隐之，不救」、两次「密奏朔日有食」。神谕可逐条判真伪，是引言里与扎哈比驳斥阿布·沙马并列的好例子。

## 2. 文本特点与坑
1. **外紀卷之二（趙氏/南越）里的 20 条「晦，日食」是转录《漢書》的汉代记录**，用汉历「晦」记日食，编辑还加了「（公元前二〇四年）」。按 S33 对转抄的处理：**不算独立见证**，可作为「与《漢書》同日」的旁证标签；观测地应为长安而不是越南。建议单独一个 `provenance: han_copy` 字段，默认不进 VN 的 π 统计。
2. 本紀/續編的记录格式：`〔干支年〕〔年号〕N年 春/夏/秋/冬 M月 〔干支日〕，朔，日食` 或 `M月，朔，日食`（无干支）。例：「庚辰乾符有道二年春正月，丁亥朔，日食」「己酉四年春二月辛酉，朔，日食，日月色赤如血」「夏六月庚子，朔，日有食之既」。
3. 年头的写法：卷内每年以「干支 + （年号）N年」起头（如「癸巳五年」「戊辰十九年」），**干支年 + 年号序数可以唯一定年**，不需要先验年号表——用它当主键；年号表只用来消 60 年周期歧义和做自检。
4. 月食常带「望」或「十五日/十六日」，少数带时辰（戌時 19–21h、卯時 5–7h、五更初刻 ≈ 3–4h）——可做月食**时刻**层面的核验（NASA 典范给食甚 TD，加 ΔT 与升龙经度 7h 时差）。
5. 维基文库标注 Textquality 50%，有 OCR 错字（如「聀」= 職、「𧗱」= 術、「歳」= 歲、「蝕/食」混用、「，、」混用）。匹配空间要把 蝕→食、歳→歲、晝→昼/晝 都归一；小注用 `〔…〕` 括起（本脚本已把 `{{*|…}}` 转成这个括号）。
6. 「史臣吳士連曰」「史臣曰」之后是史论，里面也提「日食」「星流」，**不是观测**，整段跳过（与《明實錄》里奏疏提及的处理相同：只收条目头部或「是日/是月」直接引出的）。
7. 屬明時期（1414–1427）记录可能来自中国文献，站点存疑；陳末–胡朝 1400–1407 都城在西都（清化）。

## 4. 建议的构建顺序（复用高麗 / 日本流水线）
1. `probe`：按卷切年条（年头正则 `^(干支)(年号)?(\d|[一二三四五六七八九十]+)年`），统计每卷年头数与覆盖年份；年号表与干支互校，不一致的年头列出来人工看。
2. `selftest`：只用 **干支+朔+日食** 27 条：干支日 → 在该年该月（±1 月容差，越南历可能差一月）里找到该干支日的儒略日 → NASA 食典 @ 升龙 ±1 天判成立。**预期成立率 0.75–0.90**（高麗 0.98、日本 0.95、明實錄 0.88）；≈ 0.1 就是年或月解错。
3. `build`：五层照冻结规则（SE/LE 朔晦望锚点；PL/MO 用 `build_sky_x_all.pl_mo`；VD 用 venus 层），`provenance` 标 `han_copy` 的外紀记录单列。
4. `freeze_v1_9_sky.py --batch vn`，接 `build_natural_sky` / `annotate_sky_x` / `build_sky_en --expansion`（英文名：Đại Việt sử ký toàn thư；朝代英文 Đinh / Early Lê / Lý / Trần / Hồ / Later Lê / Mạc）、`freeze_final`、全链审计。
5. 许可：底本公有领域（{{PD-old}}），维基文库校对层 CC BY-SA 4.0——`audit_license.py` 来源表加一行，引用 zh.wikisource.org 与 `MANIFEST.json` 里的修订号。
