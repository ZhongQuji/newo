**优点**

## 评委 2 · 信息抽取 / 多语种流水线评委：十种文字六种历法共用一套神谕是亮点，但各解析器的系统误差如何进入标签几乎没有量化，部分层的日期精度未被任何检验覆盖

**分数**：5 / 10，置信度 4

**优点**
1. 每个解析器都有内置自验：高麗 SE 124 解 122 成立、随机水平 0.10（L1824）；日本 110 解 104（L1826）；AR 相位自校 67/72、星期自校 28/29（L2684）；LA 用 Hydatius 自写星期互证（L1930）。
2. 解析失败处理透明：實錄三轮修正（L881）、AR 六轮十余处（L2513）都记录了错因和数字。
3. 复位王、踰年称元等历法陷阱（L1581）处理专业，并把「王年表错一年会崩到 11%」写成可检验预期（L459）。
4. 跨历法实验（L2690：回历换算只对 16% 却照样盖章）把换算对错与结论脱钩变成可测量。

**问题**
1. **blocking** — 「物理成立率与冻结五层同量级 ⇒ 日期解对了」（L881）只对 SE/LE/MO 成立。行星日行 < 1°（L244 自认），金星离日角日变化也约 1°，PL/VD 日期错 1–10 天成立率几乎不变，PL 66% vs 65%、VD 94% vs 95% 对日期正确性是零信息；近边界 PL 孪生「移到 2.2–5° 的最近一夜、最多 ±45 天」（L1591、L1828）恰在此盲区，PL 自然错误裕度 1.7° 也可能只是日期偏差。修复：每层做日期扰动敏感曲线——全体日期平移 k ∈ {±1, ±3, ±10, ±30} 天重算成立率，报告降到随机水平所需的 k；k > 1 的层另找日级证据：与《中国古代天象记录总集》、刘次沅《诸史天象记录考证》、Huber–De Meis（巴比伦）、Said–Stephenson（阿拉伯）、Newton（中世纪欧洲）食表逐条对齐。成本：免费，对齐约 20 人工小时。
2. **major** — 选择效应。只收「月首形态的月份标记」「朔日条目头部或是日引出」（L881），丢弃假干支「己子」等不可解析条目——不可解析本身常是传抄错误，等于把一类自然错误从「史官记错」样本中系统剔除，评测对象偏向写法规范的记录。修复：发布每源 dropped 计数与原因分布（L455 已有 note）；随机抽 100 条 dropped 由人判能否定日期，可定者补标；自然错误定义限定为「可解析且物理不成立」。成本：免费 + 5 人工小时。
3. **major** — 解析器是对着神谕调出来的。實錄 SE 从 27% 调到 88%（L881），AR 六轮 probe 到 0.76（L2514），BA 的 Nisanu 规则按「让最多记录落在容差内」从四种中选出（L2844，17/31）再标同一批记录——后者是循环论证，前两者会把「预报未见、当月无食」等合法真实负例当成解析错误剔除，抬高 π。修复：规则冻结后在未看过的卷（實錄另一朝、OpenITI 另一部）报成立率；BA 改用已数字化的 Parker–Dubberstein 全表独立定月首，Nisanu 规则只做留一法报告；π 按规则版本列表。成本：免费。
4. **major** — 容差与日界不统一，解析误差直接变成标签差异。中国层干支/朔晦 ±1 天（L1586），AR/BA ±2 天（L2513、L2785），BA 日始于日落、LE「按夜定位」，中国层子夜后 LE/MO 归哪天未说明；同一个「差一天」在不同层可能分别被判真、判假、不可构造。修复：容差表进数据卡；各层子夜后 LE/MO 在两种日界下重算、报告翻转数；跨层比较 F 按裕度分箱配对。成本：免费。
5. **major** — 见证独立性按「≥ 2 部」定义（L344）忽视文本谱系。明史天文志取材于實錄，清史稿取自清實錄，伊本·凯西尔承伊本·焦齐，阿布·沙马一错三抄（L2686）——都是转抄不是独立观测，P17「多证与单证无差异」在此定义下不可解释。修复：建源间依赖 DAG，仅跨连通分量且细节（时刻/食分/方位）不全同者记独立；重做多证/单证分层；AR「≥ 2 位史家」的 22 次按此重分。成本：免费，约 8 人工小时。
6. **minor** — 简繁转换副作用。實錄显示串用 OpenCC s2t（L445），干支「丑」候选含「醜」，「后/後」「历/曆」多对一，可能产生冻结层没有的字形而成「源可识别」线索。修复：正则扫描显示串的六十干支是否完整、统计仅在實錄层出现的字。成本：免费。
7. **minor** — 错误传播无量化框架。修复：每层给出误差预算 ε = ε_抽取 + ε_换算 + ε_神谕，前两项由对齐与人工核验估计，第三项由敏感性分析估计；用 F_obs = F_true·(1−ε) + ε·F_wrong 的界说明主结论（pro F 0.90 vs flash 0.23，L1301；P17 差异 ≤ 0.1，L884）在 ε 多大以内仍成立。成本：免费。

**若要我接收，必须看到**
1. 日期扰动敏感曲线，以及 PL/VD 与外部考证目录的逐条对齐结果。
2. 规则冻结后在 held-out 卷上的成立率；BA 用 PD 表独立定月首后的标签。
3. 以谱系 DAG 重定义独立见证后的多证/单证分层表。

**我可能误读的地方**
1. 若 `--sky-sample 0` 意为天象层全量审计，且 audit_labels 对 PL 做了干支反推儒略日的回解析（L1824「回解析 0 不符」），则换算已有程序证据，问题 1 只剩抽取与原文对齐。
2. 若 BA 的 36 条日级记录已全部与 Parker–Dubberstein 对过（记录只提两个锚点，L2785、L2844），问题 3 的 BA 部分可撤。

## 评委 3 · 历史天文学 / 天体力学领域评委：神谕用法总体规范，但判据与不确定性没有任何敏感性分析，「史官记错」这个核心类别在天文学上站不住

**分数**：5 / 10，置信度 4

**优点**
1. 双神谕 + JPL Horizons 独立核对（L231–232、L1318）和 Parker–Dubberstein 锚点复现（L2785）表明工具链不是黑箱。
2. 以观测地（都城 / 开城 / 作者城市 / 巴比伦）重算星历而非只查全球食表（L1831「在开城重算星历 0 失败」）。
3. 带符号裕度作为连续量被保留（L344），为敏感性分析留了接口。
4. 自然错误三档严重度与旁证数设计（L243）方向正确。

**问题**
1. **blocking** — 「犯」的角距判据与目标识别决定 PL 自然错误是否存在。传统「犯」约七寸（≈ 0.7°），实际记录角距有 2–3° 长尾，且星官（轩辕、太微等）跨度数度，记录未必指代表星。PL 自然错误裕度中位 1.7°（L883）正落在模糊带：换 2° 判据或改用星官最近成员，大半「史官记错」会消失，P17 在 PL 上的结论随之改变。修复：① 判据扫描 0.7 / 1 / 1.5 / 2 / 3°，报告每层 π 与自然错误数变化；② 距离改为「到星官任一成员的最小角距」，同时报告代表星版本；③ PL/MO 自然错误按「判据边缘 / 识别歧义 / 平移 ±1 或 ±30 天即成立 / 真不成立」四分，只有后两类可称记错。成本：免费，CPU 数小时。
2. **blocking** — 「物理不成立 = 史官记错」混淆了预报与观测。中国、日本、高麗的日月食记录含大量按历法推算、未经观测的预报食，月食尤甚；BA 层一半是「omitted」预报（L2844）。「预报之食未见」是史官对失验的真实陈述而非错误；现在 BA 把它们算进 π = 0.50 的分母，中国层把月亮在地平线下的食判成「记错」。修复：增加 claim_type ∈ {observed, predicted_omitted, predicted_unobserved, computed}；BA「omitted」改判为「该夜巴比伦无可见本影食 ⇒ 真」，π 按 observed 单报；中国层地平线下的 LE 单列为 computed 候选。成本：免费。
3. **major** — ΔT 与可见性判据无敏感性分析。公元前记录 ΔT 本身 4–6 小时，各模型间差 O(10³ s)；1 小时即 15° 经度、约 1,400 km 影带位移，半影边缘的日食可见性随之翻转。NASA 典范与 PyEphem 的 ΔT 公式不同，99.91% 一致可能只因公元前记录占比小；食分阈值、地平高度阈值、白昼月食处理从未给出。修复：① 1000 年以前的 SE 以 ΔT ± 2σ（Stephenson–Morrison–Hohenkerk 2016）重算，报告翻转条数并加 dt_sensitive 标志；② 公布并扫描判据：日食 mag ≥ {0, 0.2, 0.5} × 太阳高度 ≥ {0°, 3°}，月食本影且月高 > 0；③ 双神谕 0.09% 不一致按年代与裕度报告。成本：免费，CPU 小时级。
4. **major** — 「差一天」在 SE/LE 层不可分辨为记错。定朔（665 年）以前用平朔，历朔与真合朔可差一天，干支是绝对纪日但「朔」字相对历法；子夜后的月食按「夜」归前一日是常规而儒略日已换日。因此 SE/LE adjacent 档（L243）与干支 ±1 规则（L1586）下的「差一天」自然错误多是历法/日界约定，不是记错；MO 月行 13°/天则可分辨。修复：计算 LE/MO 子夜后发生比例并在两种日界下重标；SE/LE adjacent 档改名「历法歧义」并从 P17 记错样本剔除；困难孪生只保留 MO 与 PL。成本：免费。
5. **major** — 太白昼见判据过松。按 L243 分档推断阈值在离日角 20° 左右，而金星约四分之三时间离日角 ≥ 20°，随机日基线可能已达 0.7 以上，π = 0.95 信息量很低；pro 的 F 0.93（L1301）与 π 几乎相同，不能排除模型只在学基率。修复：报告每层随机日基线（高麗 SE 已做，L1824）；VD 判据加亮度 ≤ −4.0、金星与太阳高度差，「经天」类单列；F 按离日角分箱报告。成本：免费。
6. **major** — 观测地假设。明 1421 年前都南京，元有上都夏季行在，宋分开封/临安；AR 以作者城市为站点（L2512），但塔巴里、伊本·阿思尔汇编全伊斯兰世界消息；日食可见性对 1,000 km 量级敏感。修复：SE 以候选站点集合（都城 + 2–3 备选）重算，不一致者标 site_ambiguous 并从困难孪生与自然错误剔除；数据卡列每朝站点与时段。成本：免费。
7. **minor** — 缺综合敏感性输出。修复：每条记录发布 label_stability ∈ [0, 1]（ΔT、判据、站点、日界、容差全部组合下标签一致的比例），主表附 stability = 1 子集的 F/H 作稳健性检验。成本：免费。

**若要我接收，必须看到**
1. 「犯」判据与星官成员敏感性表，以及按四类重分后的 PL/MO 自然错误计数。
2. claim_type 字段与按 observed 单算的各层 π，BA omitted 改判后的结果。
3. ΔT ± 2σ、可见性阈值、站点三项的标签翻转表与 label_stability 分布。

**我可能误读的地方**
1. 若 PL/MO 的星官已按成员集合建模而非代表星，问题 1 的 ② 可撤，但判据扫描仍要做。
2. 若中国层 LE 的 ±1 天规则本就是为子夜后事件设计并已在两种约定下验证过，问题 4 降为 minor。
