## 评委 1 · RLVR / RL 理论评委 —— 审计证据扎实，但「RLVR 导致盖章」的因果链与吸收态理论都停在二臂玩具层面，现状撑不起主会方法论文

**分数**：4 / 10　**置信度**：4 / 5

**优点**
- 替代解释排除得干净：同记录英 / 中 F 无差（McNemar p 0.24–0.77）、旧 / 新切片无差、「一半伪造」提示反使 pro 的 F 上升（LE 0.53→0.87），记忆、格式、先验校准三条路都封了（L1302–1303）。
- 「信 / 验 / 编」可操作：被盖章负孪生里账本正确仅 SE 11/54、VD 1/54，伪推导率四到六成（L1304）。
- 预注册 P9 / P10 / P17–P20 逐条兑现（L1307、L1835–1836、L1932），研究纪律好。
- E9：LLM 评委对编造账本 AUROC 0.49–0.71（L1305），是对「拿评委做过程奖励」最硬的反例。

**问题**
1. **blocking** · 中心因果主张没有一次完整生成的 RL 证据。20 个运行全是 Qwen3-1.7B 决策级二臂 CHECK / STAMP，a、c、π 是环境参数而非模型涌现量（L1313、L1596–1598、L1834）。命题 3 本身就是两臂期望奖励比较，模拟器按它实现，GRPO 只是在解一个上下文 bandit，「预测命中」接近同义反复。审计只证明现成模型会盖章，没证明 RLVR 导致或加剧。修复：① 1.7B 完整生成 GRPO，VD + 一个文档层，{outcome-only, TAPO, TAPO-RA q=0.3} × 3 种子，每 20 步记录 F、H、伪推导率、账本正确率曲线；② 并行做 E-B 谱系审计（OLMo-2 SFT→DPO→RLVR、Qwen3 base / instruct，L1338），看 F 与伪推导是否随 RLVR 阶段单调上升。成本：① 30–60 消费级 GPU 卡时或约 20 A100 卡时；② 本机推理，免费。
2. **blocking** · 「GRPO 零方差吸收态」不严格且依赖实现变体。softmax 策略从不精确到达 p∈{0,1}，看到的是亚稳态，期望更新 ∝ p(1−p)·Δ，任何带基线的 on-policy PG 都如此，与 GRPO 无关。GRPO 特有的两点反而没讨论：(a) 组内 std 归一化下，一个稀有逃逸样本的标准化优势约 ±√(G−1)，稀有事件被放大而非吸收（Dr. GRPO 去掉 std 正因此）；(b) 若 KL 系数 β>0，固定点满足 p(1−p)Δ = β(logit p − logit p_ref)，根本不是吸收态。修复：写明 look_rl.py 的 G、β、clip、是否 std 归一化、序列级或 token 级损失；把命题改写为「给定变体下从 p₀ 到 p₁ 的锁死步数上界 + 有限 G 下无梯度组比例 p^G+(1−p)^G 的修正」，并用已有 20 条曲线拟合检验。成本：免费。
3. **major** · 命题 1 的 c 在真实 RLVR 里没有操作定义：outcome-only 奖励不含查证成本，c 只能来自长度惩罚或 KL；若 c≈0，故事退化为比较 a 与 π。闭卷下模型本就算不出食日（a≈随机），盖章是能力受限下的贝叶斯最优，谈不上「悖论」；悖论只在「能验而不验」处成立——事实在手 F=0、带工具不调用 ≤2.5%（L1301）说明天象层这个格子其实很小，真正的证据在文档层「作者印错的页面 85–95% 被判一致」（L1306）。修复：按层 × 条件报告 a（模型真去验时的准确率）与 π；c*(π) 相图（L1308）的 c 轴要么换成可观测惩罚，要么明示为模拟参数；主叙事以「a 高而 F>0」的格子为锚。成本：免费，重算已有运行。
4. **major** · 逃逸概率 1−(1−p)^{G·n}（L1334）统计的是「有样本探索」，不是「探索被奖励」。outcome-only 下探索样本落在真记录（概率 π）时 reward 1−c<1，优势为负，反而加深锁死；只有落在负孪生且算对（概率 (1−π)a）才是有效逃逸，TAPO-ε 救回靠的是孪生保证组内有负例，不是 ε。修复：改写为有效逃逸 1−(1−p·s)^{G·n}，s 按奖励方案推导，与 P10「10 步救回」（L1307）对拍。成本：免费。
5. **major** · P19 接种「100 步后仍 0.976」（L1932）有更朴素的解释：p≈1 处同样亚稳，G=8 时只有 1−0.976^8≈18% 的组产生梯度。纯 logistic 动力学下 0.976→0.5 与 0.5→0.02 所需时间几乎相等，「≥3 倍」只能来自有限 G 效应，请写出推导；接种延长到 ≥500 步、≥3 种子，看是否最终锁死；P9 跨层迁移要加「打乱层标签」的零假设对照。成本：本机数小时 GPU。
6. **minor** · 定位：零方差组被 DAPO 动态采样直接丢弃、熵塌缩、spurious reward 等文献已讨论同一机制；TAPO-RA 与 PRM / verifier-based RL 的差别应写成「稀疏、随机、神谕锚定、只审瓶颈事实、不可被评委式欺骗」，并与 AI-control 的审计预算（Greenblatt 等 2024）和形式化过程监督比较，而非只与 LLM 评委比。成本：免费。

**若要我接收，必须看到**
- 完整生成 RL 中 F / 伪推导率随训练步数上升、TAPO 或 RA 使其回落的曲线（1.7B 即可，3 种子）。
- 明确变体假设下的吸收态命题，以及锁死时间公式与 20 条实测曲线的拟合。
- 分层 a × π 表，证明存在「a 高而 F 高」的格子。

**我可能误读的地方**
- 「决策级」若实际让 1.7B 生成账本、a 由其计算结果决定，问题 1 降为 major。
- 若 look_rl.py 已是 β=0 且无 std 归一化，问题 2 只需补命题陈述与拟合。

## 评委 2 · 机制设计 / 经济学评委 —— 把奖励当审计合同是对的方向，但只比较了两种固定策略、没有激励相容分析，伪造与弃权两条逃逸路线都没封

**分数**：5 / 10　**置信度**：3 / 5

**优点**
- 命题 3 阈值 q* = (π+c−a)/(κa) 结构清楚，VD 的 q*=0.26 被两侧实验命中（q=0.3 第 15 步到 1.0；q=0.1 第 100 步 0.001，L1835–1836），定量预测加兑现在这类论文里少见。
- 审计对象是「瓶颈物理事实」这一可核验原子主张而非整段推理，与 Townsend 的核验状态同构。
- 抽签用确定性哈希，审计本身可被审计（L1596）。
- 「诚实弃权不审」在直觉上把无知和装懂分开。

**问题**
1. **blocking** · IC 只对 {盖章, 查证} 两个纯策略算了期望，代理的真实最优反应是第三、四策略。(a) 伪造一本能过审的账：伪推导率已达四到六成（L1304）；若审计对瓶颈数值有容差、伪造值以概率 p_pass 通过，则伪造期望 = π − qκ(1−p_pass)，q* 要除以 (1−p_pass)。(b) 懒惰弃权：弃权报酬 r_abs 不受审，在 a 低的层（CH 带工具 c* = −0.44 / −0.58，L1308）存在 qκ 区间使弃权同时优于盖章与查证，GRPO 下全组弃权就是新的零方差吸收态，与要治的病同构。修复：决策级模拟扩成四臂 {盖章, 查证, 伪造, 弃权}；用现有运行估 p_pass（把被盖章负孪生的账本数值送进审计器看通过率）；给 r_abs 定价（建议 r_abs ≤ −c，或弃权以较低概率受审、仅当神谕判定「事实可由给定信息算出」时罚）。成本：模拟免费；决策级 RL 约 8 个运行、本机数小时。
2. **major** · Becker「罚金拉满、审计率压低」的杠杆在 GRPO 里被组内标准化抵消：优势只取决于组内排名与相对差，κ 从 1 到 4 不会让推力放大 4 倍，κ 极大时查证与未被审盖章的优势趋同。命题 3 的 κ 依赖只在 κ=1 测过。修复：κ ∈ {0.5,1,2,4} × q ∈ {0.15,0.2,0.25,0.3}，3 种子，检验边界是否按 q*∝1/κ 移动；若不动，理论须改写为排名型目标。成本：决策级 48 运行，本机 1–2 天；可先用玩具模拟器筛格子。
3. **major** · Townsend / Mookherjee–Png 的结论是随机审计应依报告而定：便宜的报告（「一致」）审得更重。盖章只表现为「一致」，等预算下「只审盖章」应严格优于均匀 q，但现在没有对照。另外必须回答「神谕几乎免费为何还随机」：若审计零成本，q=1 平凡占优，TAPO-RA 的意义只能是部分可验证性模型（q = 恰好可核验的主张比例）或把显式审计成本写进目标。修复：论文明确 q 的语义并把审计成本写进目标函数；加「报告依赖审计」对照做等预算比较。成本：免费 + 模拟。
4. **major** · 固定 q 对学习代理的余量不够。检查博弈（Avenhaus–von Stengel–Zamir）的均衡假设理性对手，学习代理在 q 略高于 q* 时会因有限样本噪声随机锁死；q=0.3 对 q*=0.26 余量 0.04 且单种子。修复：q ∈ {0.2,0.25,0.3,0.35} × 3 种子测边界宽度；再做自适应 q_t = clip(q_min + k·(F̂_t − F_target))，F̂ 每 K 步在留出孪生探针上估计，报告 q 下调期是否复发。成本：约 15 个决策级运行。
5. **minor** · 哈希 (条目, 回答) 使同一条目的固定回答串（如「一致」）在所有 epoch 审计状态恒定，重复采样时形成可被记忆的「永不被审」子集。改成 (条目, 回答, 步数, 盐) 或记录种子的 RNG。免费。
6. **minor** · 多层异质 π 的预算分配未做：q*_SE<0、q*_VD=0.26、低 a 层可能 >1；且 P9 显示查证习惯跨层迁移（L1307），IC 应在策略层面而非逐条目成立。实验：只审一层，测其他层 P(CHECK)，若有正溢出，预算集中到溢出最大的层。成本：决策级 5 运行。
7. **minor** · 命题 1 / 3 是信息价值（Wald 序贯检验、理性忽视 Sims / Caplin–Dean）的特例：验证价值 ≈ (1−π)·a₀ − π·(1−a₁) − c，a 在真 / 假记录上不对称时阈值会移动；写成一般式，并把「不能验（a≈随机）」与「不愿验」分开。免费。

**若要我接收，必须看到**
- 四臂 IC 分析 + 弃权定价后的实验，证明没有新的吸收态。
- κ–q 相图至少 2×3 格、3 种子。
- 报告依赖审计 vs 均匀 q 的等预算比较。

**我可能误读的地方**
- 不清楚 audit 方案里弃权奖励数值与审计是否按数值容差判；若 r_abs 已为负且容差近零，问题 1 降为 major。
- 若决策级实现用的是无 std 归一化的 REINFORCE 基线，问题 2 弱化为「需说明」。

## 评委 3 · 效率 / 系统评委 —— 数据与审计链条是 D&B 水准，但方法层没有任何等预算比较，评测样本量与统计目标自相矛盾，可复现性系于一台 Windows 机器

**分数**：5 / 10　**置信度**：4 / 5

**优点**
- 标签审计规模与纪律：929,975 项 0 失败、评测 / 训练 id 交集 0、双神谕一致 ≥0.998、每次并源都重冻全链（L1164、L2508、L2574）。
- 「免费的新结果」：report_natural_sky 复用 80 个既有运行文件出新表（L886），珍惜评测 token。
- 决策级 RL 在消费级 GPU（4060，L1338）上 100 步出相边界，是便宜的试错范式。
- 流式读取修 MemoryError（L890、L2524）等细节说明流水线被真实跑过多轮。

**问题**
1. **blocking** · 没有任何等预算比较，且成本单位选错。物理 / 数学神谕是微秒级且可离线缓存，TAPO「每样本 3 次神谕」的真实成本是 3 倍 rollout（真 + 负 + 正孪生各采 G 次），RA 的 q 次审计几乎不花 token，「只审盖章 1.2 次」同理；换成 web / 人工神谕则相反。修复：定义成本三元组（rollout token、神谕 CPU 秒、墙钟），对 {outcome, balanced, TAPO, TAPO-2（去正孪生）, RA(q), RA(q=1), 只审盖章} 报告「达到 P(CHECK)≥0.95 所需 rollout token」与同 token 下终值，3 种子；先决策级模拟（免费），再 1.7B 完整生成验一个层。成本：模拟免费；完整生成约 30 GPU 卡时。
2. **blocking** · 评测样本量与统计目标不自洽。目标写「每类 60、主表 CI 半宽 ≤0.09」（L1323），但 F=0.5 时 n=60 半宽 0.127，F∈[0.2,0.8] 需 n≈120，flash 的 F 0.23–0.38 正落在此区间。P17「自然错误 = 孪生替身」靠每格 8–30 条的 McNemar p≥0.25 得出「无差异」（L886），是无检验力的缺席证据；跨历法 n=20 / 40 的半宽 ±0.15–0.22（L2576、L2690）。修复：主表 n=120 / 类；P17 改 TOST 等价检验（边界 Δ=0.10，每格 ≥150）或跨层分层 logistic 合并估计；功效分析写进预注册。成本：约 2 倍现有 API 量，$200–500。
3. **major** · 可复现性。PowerShell 队列 + `C:\Compiler\python.exe`、31 GB 机器反复 OOM、全链约 1 小时（L879、L890、L2524）；模型经第三方网关且版本未钉（L1312）；NASA 食典在线抓取且 SSL 失败（L2847）；星历核与 ΔT 模型未说明，而古代日食当地可见性对 ΔT 极敏感。修复：Dockerfile + Linux CI 在 16 GB 内从原始文本重建 final/ 并比对哈希；食典、DE 核、ΔT 表随包 vendoring 并记校验和；报告 ΔT ±1σ 下 SE / LE 标签翻转数；API 运行保存完整请求 / 响应、模型 ID、解码参数。成本：免费至数 CPU 小时。
4. **major** · 同样 token 怎么更好（目前零消融）：(a) 结构化短账本（JSON 只填瓶颈数值与结论），输出 token 降 3–5 倍且审计零解析歧义；(b) 真记录与其负孪生放进同一 GRPO 组，组内基线天然对比，2 倍 rollout 取得 TAPO 的信号；(c) 按裕度做课程，近边界孪生（PL 2.64°、MO 10.9°，L1829、L882）每 token 信息最多；(d) 审计按「一致」判决加权抽样并以逆概率权重保持无偏。先在模拟里逐项量化。成本：模拟免费。
5. **major** · 更少 token 怎么不差（同样零消融）：q 退火到 q_min 并证明 q_min 仍在边界之上（接种滞后作安全边界）；孪生比例 1:4 而非 1:1:1；决策级热启动再完整生成微调。没有这些，不能声称 RA 比 TAPO「省」。成本：模拟 + 几个 1.7B 运行。
6. **minor** · 8B 预算「300–450 A100 卡时」（L1319）对应 24 运行、每运行 12–19 小时，没写 G、步数、最大长度、推理引擎；应先用 1.7B 完整生成实测吞吐外推。免费。
7. **minor** · 评测工程与算力声明：三个条件共享提示应复用缓存并去重；真正瓶颈是配额（MiMo 10-22 耗尽 L233、网关余额 −0.75 元 L2873），论文应如实写明并给出每实验调用数 / token 数表。免费。

**若要我接收，必须看到**
- 等 rollout-token 的方法对比图（≥3 种子）。
- 主表 n≥120 并附功效分析；P17 等价检验。
