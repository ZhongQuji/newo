## 评委 1 · LLM 评测方法学 —— 基准骨架与神谕扎实，但「被测对象经网关、样本量小、记忆未排除」让主表目前不可引用

**分数**：5 / 10；置信度 4 / 5

**优点**
1. 标签不依赖 LLM：物理神谕 + 第二神谕交叉核验 ≥ 0.998、全库标签复核 929,975 项 0 失败、评测/训练 id 交集 0（行 1163、2507、2571），是同类「LLM 查证」基准少有的硬地基。
2. 真记录 / 负孪生 / 正孪生 / 自然错误四类 + 闭卷 / 事实在手 / 带工具三条件 + 「无主张探针」，把信、验、编拆开测（行 1301–1306、2519），指标设计明显优于只报准确率。
3. P1–P21 预注册与事前预测（行 1307、1596–1598），报告脚本离线可重跑（行 247）。
4. 六种历法、四种文字共用一个神谕（行 2849），为「不是记忆、不是历法格式」提供了别处没有的对照面。

**问题**
1. **[blocking] 被测对象经网关，身份与版本不可核。** MiMo 5 型号走 token-plan 网关；gemini-3.5-flash-lite / deepseek-v4-flash 走人民币计价的第三方中继（行 2873「剩余 −0.75 元」）。中继可静默换模、注入系统提示、切换思考模式；汇报里没有响应 model id 回显、版本串、运行日期锁定。修复：每个运行文件记录返回的 model 字段、请求日期、温度、思考开关；随每批跑 20 条「指纹题」（家族特有 tokenizer / 知识截止怪癖）；主表至少一家通过官方 API 复跑 2 层 × 3 条件，报与网关结果的配对一致率（目标 ≥ 0.95）。成本：官方 API 约 $30–80；指纹免费。
2. **[blocking] 天象层未区分记忆与推理。** 旧 / 新鲜切片只有文档层（行 1302）；二十四史、殆知閣明實錄、维基文库六国史、OpenITI 全是公开预训练语料。真记录和「史官记错的日子」都在被记忆的原文里，pro 对自然错误的 F = 0.88（SE，行 886）可能是复述记忆而非盖章；跨政权 / 跨历法切片同样是公开文本，不构成「新鲜」。修复：对每条母记录做 cloze 记忆探针（给前文让模型补日期 / 天体，或用本机开源模型算原文 PPL），按记忆分三档分层报 H / F / F_natural；加「合成朝代」对照（历表骨干换成虚构年号，物理事件不变），其 F 应与真史书相当才算排除记忆。成本：API $20–50；PPL 本机免费。
3. **[major] 每格样本量过小且无多重比较控制。** 自然错误表每格 8–30（行 886），VD 仅 5、SE 18（行 1343），跨历法 n = 20 / 40（行 2517、2690）。14 层 × 5 型号 × 3 条件 × 多指标是数百个格子，p ≥ 0.25 在此 n 下无信息。修复：主表每类 ≥ 60（p 远离 0.5 时 Wilson 半宽 ≤ 0.09；p ≈ 0.5 需 ≥ 120）；所有格子报 Wilson 95% CI；按预注册假设族做 Holm 校正，未预注册结果标「探索性」。成本：API $200–500。
4. **[major] 提示敏感性未测。** `harness_v2.prompt_for` 每层单一模板，高麗只换两处措辞（行 1588）；而「主张在场效应」高达 0.85（行 2519），说明措辞本身能翻转结论。修复：每层 3 个语义等价模板（含英文）× 2 种输出格式，报跨模板 F 的极差与 ICC，模板作随机效应进主模型。成本：主表 × 3，约 $150–400。
5. **[major] 三条件可比性缺对照。** 事实在手全层 F = 0（行 1301）说明任务退化为阅读；没有「安慰剂事实块」（无关真事实）和「错误事实块」，分不清是读懂了事实还是「有事实块就不盖章」。带工具的 CH 层宽 / 严口径差距 0.33–0.43 vs 0.04–0.25（行 1342）要统一到严口径。修复：两组对照各 n = 60；所有工具层报「调用 → 使用 → 结论一致」三段漏斗。成本：API $50–100。
6. **[minor] 泄漏口径过窄。** id 交集 0 不等于无泄漏：同一次食被多部史书记录（中韩同日见证 201，行 1823）、孪生与母记录同事件、英中同记录。修复：split 以「物理事件（类型, 日期, 站点）」为组键；near-dup 审计（行 2523）报跨源同事件数；hard 系列只评 hard_heldout（行 1343）写进数据卡。成本：免费。

**若要我接收，必须看到**
1. 至少一家官方 API（锁版本）+ 指纹核验，主表每类 n ≥ 60 带 CI。
2. 天象层记忆探针分层：高 / 低记忆档的 F 差 < 0.10，否则把差写进结论。
3. 3 模板提示敏感性 + 安慰剂事实块对照。

**我可能误读的地方**
1. 跨政权 E-X（高麗 / 日本）数字未出现在我读的汇报里（只见「与高麗一致」，行 2520）；若已有 n = 60 结果，第 3 条部分缓解。
2. 网关是否回显 model id 我无法确认；若 runs/ 文件已记录，第 1 条降为 major。

## 评委 2 · 统计与因果推断 —— 配对设计方向正确，但「无差异」靠的是功效不足、混杂未建模、RL 结论建立在单种子上

**分数**：4 / 10；置信度 4 / 5

**优点**
1. 配对设计（同记录英 / 中、同母记录孪生、同模型同条件）与 McNemar 用对了地方（行 247、1302）。
2. 事前预测 20 / 20 命中与 P17–P21 预注册（行 1307、1596），降低了事后挑结果的嫌疑。
3. 裕度匹配做到了量化（SE 29.5 vs 29.7 天），并在发现 PL 不匹配（1.7° vs 17.2°）后补近边界孪生（行 886、1828），说明在意匹配质量。
4. 「自然错误 vs 构造孪生」是对孪生外部效度的直接检验，设计正确。

**问题**
1. **[blocking] 用「不显著」当「等价」。** P17「史官记错与同裕度孪生无可分辨差异」全部基于 McNemar p ≥ 0.25、每格 8–30（行 886）。n = 30 对时检出配对差 0.15 的功效不足 30%，「等价」没有任何证据。修复：预设等价边界 δ = 0.10，做配对 TOST（两个单侧 α = 0.05），报配对差的 90% CI 是否落入 (−δ, δ)；按现 n 几乎必然「等价未建立」，要么补到每格 ≥ 150 对，要么改写为「未检出差异（功效 X%）」。成本：API $100–300 / 改写免费。
2. **[blocking] 混杂未建模，相图是层级散点。** F 的跨层差异同时携带 π、史源、时代、语言、记录长度、歧义度；c*(π) 相图把层当点拟合（行 1308），点数 ≤ 14，任何单调关系都「拟合得上」。修复：条目级混合效应 logistic 回归：结果 = 判一致；固定效应 = 条目类型 × 条件 × 模型 + π（用层内 pisweep 操纵，行 248）+ 语言；随机截距 = 母记录 / 物理事件、史源、模型 × 层。c*(π) 的斜率用层内 π 扫描估计并 bootstrap CI，跨层散点只作插图。成本：免费（statsmodels / lme4）。
3. **[blocking] RL 证据的方差未知。** 20 个运行覆盖 ≥ 8 种配置（TAPO、TAPO-ε、RA q = 0.1 / 0.3、接种 s0 / s1 …，行 1307、1834、1932），多数配置单种子；接种 s1 在 50 步被停（行 1963）；「相边界命中」是 2 个 q 值各 1 个种子。修复：每配置 ≥ 5 种子；q ∈ {0.15, 0.20, 0.25, 0.30, 0.35} 扫描；报锁死步数中位数与 IQR、P(CHECK) 轨迹分位带；相边界位置用 logistic 拟合 q → P(保住) 给 CI。成本：决策级 1.7B LoRA 100 步约 20–30 分钟，合计约 25–40 卡时（4060 级）。
4. **[major] 选择效应与自然错误标签可信度。** 只有「历法自洽、精确到日」且解析器能解的记录入池（行 238）；明實錄 SE 成立率从 27% 调到 88% 全靠改解析规则（行 882）——「史官记错」与「我们解析错」在零人工核验下不可分，自然错误表因此可能混入解析错误。修复：自然错误切片（天象 235 组 + 文档 natural_decisive）100% 双人核验，报 κ 与「解析错」占比；入池 / 未入池记录按史源 × 世纪报分布，并随机抽 100 条未入池记录估计入池偏差方向。成本：人工 25–40 小时。
5. **[major] 神谕标签噪声未传播到结论。** SE / VD 可见性依赖 ΔT 与站点，BCE 的 ΔT 不确定度足以翻转边缘可见性；BA 层 π = 0.50 有一半是预报（行 2846）；±2 天容差与 521 条争议隔离（行 233）是补救但未量化。修复：对每条 SE / VD 标签做 ΔT ± 1σ 与食分阈值（0 / 0.05 / 0.10）敏感性，报标签翻转率；翻转条目剔除或标灰；主结果附「标签噪声 ρ 下的鲁棒区间」。成本：免费（重算星历）。
6. **[minor] 效应量报告不统一。** 多处只报点值（pro 0.90 vs flash 0.23，行 1301），缺配对差、风险比与 CI；「ΔF(AR−LA) ≈ −0.08，CI 含 0」（行 2690）是正确写法，应全文统一。成本：免费。

**若要我接收，必须看到**
1. 混合效应模型的主效应表（含 CI），替代逐格 p 值。
2. 自然错误切片 100% 人工核验 + TOST 结果（或明确的功效声明）。
3. RL 每配置 ≥ 5 种子的 q 扫描相边界图。

**我可能误读的地方**
1. 「每格 8–30」可能只指自然错误表，主表 F 的 n 或已 ≥ 60；若是，第 1 条只针对 P17。
2. 相图可能已用 pisweep 层内数据拟合；若是，第 2 条只剩随机效应部分。

## 评委 3 · Area Chair 元评审 —— 一个强数据集、一个有新意的审计发现、一叠尚未坐实的方法与理论；当前形态最适合 D&B 轨，主会要补家族与 8B 生成级 RL

**分数**：主会 5 / 10，D&B 6.5 / 10（补齐人工核验后）；置信度 3 / 5

**优点**
1. 数据集是真正的贡献：约 57 万条、14 层、六种历法，神谕式标签 + 全库审计 0 失败（行 2507、2849），单独成文即可。
2. 「伪查证」是全文最新鲜的发现：被盖章的负孪生里账本正确的仅 SE 11/54、VD 1/54，伪推导率 36–61%，而 LLM 评委 AUROC 仅 0.49–0.71（行 1304–1305）——用物理神谕量化「评委看不出的编造推导」，现有文献没有。
3. 回历换算只对 16% 却照样盖章（行 2690）与「主张在场效应」0.85（行 2519）是干净的机制证据。
4. c*(π) 经验相图与 q* 相边界（行 1308、1834）给了一个可预测的量，方向正确。

**问题**
1. **[blocking] 单家族 + 网关撑不起「盖章随能力增长」。** 该结论只是 MiMo 内 pro vs flash 两点（行 1301）；其它两家各 n = 20 / 40 且经中继。修复：≥ 3 家族官方 API × 14 层 × {闭卷, 事实在手} × 每类 ≥ 60；主表加家族随机效应。成本：$300–800。
2. **[blocking] 人工核验 0 条。** 200 抽检 + 50 κ + 521 争议均未动（行 233、1315）；D&B 的核心主张是数据质量，只有程序证据过不了数据卡审查。修复：三份核验做完（κ ≥ 0.8），自然错误切片 100% 复核，结果进 datasheet。成本：人工 40–60 小时。
3. **[blocking · 仅主会] 方法贡献未在生成级验证。** TAPO / TAPO-ε / TAPO-RA 只有 Qwen3-1.7B 二臂决策级（行 1313）；决策级产生不了「伪推导」，RL 证据与主论点脱节。且 Spurious Rewards（Shao et al., 2025，待核）表明 Qwen 系对 RLVR 有家族特异反应。修复：Qwen3-8B + 一个非 Qwen 7–8B，生成级 {只看结局, 平衡 / 逆先验加权, TAPO, TAPO-ε} × 2 层 × 3 种子，基线必含 DAPO 动态采样与熵奖励；报 F、伪推导率、自然错误 F、通用能力不降。成本：300–450 A100 卡时或 Tinker $1–2.5K。
4. **[major] 新颖性定位要正面交锋。** （a）「盖章」= 传播学的 truth-bias / Truth-Default；*Reasoning Isn't Enough: Examining Truth-Bias and Sycophancy in LLMs*（2025）已报告推理模型「真话准确高、假话准确低」的同一不对称；（b）verifier 失效线：*Pitfalls of Rule- and Model-based Verifiers*（Huang et al., 2025）、*RL with Verifiable yet Noisy Rewards under Imperfect Verifiers*（Cai et al., 2025）——本文的「第三种饱和：验证器无错、策略最优、行为错」必须与之逐条区分；（c）评委盲区：*One Token to Fool LLM-as-a-Judge*（2025）已示生成式奖励模型的系统性假阳性，E9 是其领域实例；（d）零方差吸收态：DAPO（Yu et al., 2025）的动态采样正是针对全对 / 全错组零优势，2026 年一篇预印本（arXiv:2607.00152，标题待核）已给出闭式「沉默组率」p^G + (1−p)^G，与本文的 1−(1−p)^{G·n} 是同一算术——理论贡献只剩「行为解释」，不宜列为独立贡献；（e）「verification paradox」一词在 LLM / RLVR 文献中未见作题名，但其它领域有用例（待核），建议 Semantic Scholar 查后加脚注或改名。修复：相关工作表「现象 / 他们怎么测 / 我们多了什么」。成本：免费。
5. **[major] 叙事三次换、正文过时。** 信还是验 → 伪查证 → 吸收态（行 1316），9 页正文仍是 S17 框架。建议定稿论点为「伪查证 + 评委盲区」（最新、最难被已有文献覆盖），盖章动力学作机制；图 1 = 伪推导率 vs 评委 AUROC，相图退为图 2。修复：先写 claim–evidence 矩阵再写正文。成本：免费。
6. **[minor] 发布许可。** OpenITI CC BY-NC-SA 只作评测切片（行 2516）、殆知閣自称公有领域（行 462）、维基文库；D&B 需逐源许可表、Croissant、托管与维护计划。成本：数小时。
