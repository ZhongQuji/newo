# 方法批判与创新备忘（S34 云端会话）

> 范围：只谈方法与理论（TAPO / TAPO-ε / TAPO-RA / 接种 / 吸收态 / 相图），不碰选题。每一条「哲学透镜」都必须落到一个可实现的机制，并且用 `sim/` 里的决策级模拟给出数字；没有数字的想法放在最后一节「想过但没做」。所有图在 `figures/S*.png`，数字在 `sim/results/RESULTS.md` 与 `sim/results/E*.csv`，代码 `sim/grpo_sim.py`（`--selftest` 10 项全过）与 `sim/run_experiments.py`（E1–E10）。
>
> 模拟是**决策级玩具模型**（四种行为：无账本盖章 S0 / 假账本盖章 S1 / 查证 C / 弃权 A；softmax 策略；GRPO 组内归一化优势；记录为真的基率 π、查证准确率 a、查证成本 c、审计率 q、审计罚 κ）。它和本机 `sim/sim_rewards.py` 是同一抽象层次，结论是「机制层面的预测」，要在 1.7B 上验证后才能写进正文。

## 0. 一页结论

1. **优化器本身是「验证悖论」的一半原因。** GRPO 的组内 std 归一化把「查证多花一点成本」放大成满幅惩罚：在全部答对的混合组里，k 个查证样本的归一化优势恒等于 −√((G−k)/k)，**与成本 c 无关**（selftest 第 3c 项；E9：c 从 0.002 到 0.2，GRPO 锁死步数都是 ~20 步，Dr. GRPO 从 648 步降到 133 步）。因此 GRPO 的有效 c* 比理论 a − π 低约 0.04（E1：GRPO 与解析边界符合 91.8%，Dr. GRPO 99.5%），有效 q* 比命题 3 的解析值高 4–5 倍（E2/E3）。**最便宜的缓解不是加奖励，而是去掉 std 归一化**——`look_rl.py` 一行改动。
2. **TAPO-RA 的三个洞都能画出边界。** (i) 伪账本：只罚「没账本」而审计不够 → 策略 99% 写假账本（E3，π=0.9、q=0.1）；(ii) 弃权陷阱：弃权奖励 r_a > a − c − qκ(1−a) 时弃权成为新吸收态，r_a = 0 永远安全（E7）；(iii) Becker 杠杆失效：GRPO 下加大罚 κ 几乎没有边际作用（E10），省 token 只能靠「审谁、何时审」。
3. **「无为而治」可以实现成一个控制器，而且省一半审计。** q_{t+1} = clip(q_t + η(观测失败率 − τ), q_min, 1)：账本感知 + 自适应，在 1.2–1.3 次神谕/样本上达到 TAPO（3 次）的查证水平，控制器自己停在优化器的真实相边界（E4）；τ 必须高于诚实查证的错误率 1 − a，否则「零容忍」把 q 推到 1 永不松。
4. **接种的「正向滞后」是吸收态的几何，不是习惯。** 滞后长度 ∝ 1/(1 − p0)（E6）；TAPO 150 步 → P(C) 0.990 → 切回只看结局 100 步后 0.981（和本机 s0 的 0.976 同形）→ 500 步后 0.007。P19 要配这个解释报。
5. **「只改数据配比」在 GRPO 下代价三倍**（E5：要混到 ≥ 65–70% 低基率提示才翻转，低于此两层一起锁死），在 Dr. GRPO 下边界 ≈ 期望奖励分析的 f* = 0.22。

## 1. 对现有方法的批判（按评委会问的顺序）

### 1.1 命题 1 / 命题 3 的隐含假设
- 两个命题都是**期望奖励比较**：盖章 π vs 查证 a − c（命题 1）；π − qκ vs a − c − qκ(1 − a)（命题 3）。它们假设优化器沿期望奖励梯度走。GRPO 不是：它沿**归一化**优势走，固定点由 E[(mean_C − mean_S)/std] = 0 决定，不是 E[r_C] − E[r_S] = 0。E1/E2 量化了偏差；在论文里应把解析边界标为「期望奖励边界」，再报「GRPO 有效边界」。
- a（查证准确率）在真实 RL 里不是环境参数，是模型涌现量；闭卷下 a ≈ 随机，盖章是能力受限下的贝叶斯最优，谈不上悖论。悖论只在「能验而不验」处成立（事实在手 F=0、带工具不调用 ≤ 2.5%）。主叙事应锚在「a 高而 F 高」的格子：带工具条件与文档层「作者印错的页面 85–95% 被判一致」。
- c 在 outcome-only RLVR 里没有操作定义（只能来自长度惩罚或 KL）。E9 恰好说明这点不重要：GRPO 下 c 的大小不影响锁死速度，只要 c > 0。论文可以把 c 定义为「任何让查证样本奖励低于盖章样本一个 ε 的因素」（多生成的 token 被长度惩罚、KL 偏离参考策略、工具调用失败率）。

### 1.2 「零方差吸收态」要改写成两层
- **第一层（精确、属于 group-relative 族）**：同组同动作 → 组内优势之和为 0 → 梯度恰为 0。对 GRPO、Dr. GRPO、RLOO、DAPO 都成立；REINFORCE + 学习基线 / PPO 价值网络没有这个精确零点，只有 softmax 饱和的渐近零点（E8：REINFORCE+EMA 与 Dr. GRPO 在 3000 步内都没到 P(C) ≤ 0.01，GRPO 207 步就到）。
- **第二层（GRPO 特有）**：std 归一化的成本盲放大（§0 第 1 条）。这才是锁死快的原因。
- 顺带修正逃逸概率：1 − (1 − p)^{G·n} 统计的是「有样本探索」，不是「探索被奖励」。在 outcome-only 下探索样本落在真记录时奖励 1 − c < 1，优势为负，反而加深锁死；只有落在负孪生且算对（概率 (1 − π)a）才是有效逃逸。TAPO-ε 救回靠的是孪生保证组内有负例，不是 ε 本身。有效逃逸 = 1 − (1 − p·s)^{G·n}，s 按奖励方案推导。

### 1.3 TAPO-RA 的激励相容只对两个纯策略算过
- 真实代理有四个策略（S0/S1/C/A）。E3 显示 RA-ledger 在 q 低时训出假账本；E7 给出弃权成为吸收态的解析条件；两者都该写进命题 3 的适用范围。
- 若审计对瓶颈数值有容差、伪造值以概率 p_pass 过审，q* 要除以 (1 − p_pass)。本机可用已有运行估 p_pass：把被盖章负孪生的账本数值送进审计器看通过率。
- 审计抽签用 (条目, 回答) 的哈希：同一条目的固定回答串（如「一致」）在所有 epoch 审计状态恒定，会形成可被记忆的「永不被审」子集。改成 (条目, 回答, 步数, 盐)。
- 「神谕几乎免费为何还随机」必须回答：q 的语义要么是「恰好可核验的主张比例」（部分可验证性），要么把审计成本显式写进目标函数。否则 q = 1 平凡占优。

### 1.4 接种（P19）与跨层迁移（P9）
- E6 的几何解释见 §0 第 4 条。证明「学牢了」需要：切换前把 P(C) 人为拉回 0.9，再比较衰减速度是否仍慢于未接种对照。
- P9 的负迁移在 E5 里以强版本复现：GRPO 下高基率层的成本盲推力（−√7/组）压过低基率层靠准确率赢的推力（≈ +0.8/组），一个抵三个。这给 P9 一个定量预测：迁移强度随共享度 s 变化，s 可用 P9 的实验标定。

## 3. Token 经济学：同样 token 怎么更好，更少 token 怎么不差

成本单位要先说清（评委 A3）：物理神谕是微秒级、可缓存，TAPO 的「3 次神谕」真实成本是 3 倍 rollout（真 + 负 + 正孪生各采 G 次）；RA 的审计几乎不花 token。模拟里统一用「神谕调用/样本（含基础标签）」计，换成 rollout token 时 TAPO 更贵、RA 更便宜，结论方向不变。

**同样 token 更好**（E3，GRPO 行，π = 0.9）：
- TAPO 3.0 次 → P(C) 0.998；RA-ledger q = 0.5 1.5 次 → 0.994；自适应 1.3 次 → 0.93–1.0。账本感知 + 自适应用不到一半的神谕达到同一水平。
- 把真记录与其负孪生放进**同一个 GRPO 组**（评委 A3 建议）：组内基线天然对比，2 倍 rollout 取得 TAPO 的信号——未模拟，是下一个该加的变体。
- 结构化短账本（JSON 只填瓶颈数值与结论）：输出 token 降 3–5 倍且审计零解析歧义。
- 近边界孪生（PL 2.64°、MO 10.9°）每 token 信息最多，按裕度做课程。

**更少 token 不差**：
- 去掉 std 归一化（零成本）。
- 层间预算：q*(π) < 0 的层不审。
- q 退火到 q_min，并证明 q_min 仍在**有效**相边界之上（E4 的控制器会自己告诉你边界在哪）。
- 孪生比例 1:4 而非 1:1:1；决策级热启动再生成级微调。
